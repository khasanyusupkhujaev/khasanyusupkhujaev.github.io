Uzbek Language OCR (2025–present, ongoing)
Khasankhon Yusupkhujaev
Independent Research, 2025–present
We are developing the first OCR system explicitly trained for the Uzbek language. Unlike existing OCR tools, which are not optimized for Uzbek script and often produce poor accuracy, our project leverages a curated and cleaned Uzbek dataset. We are currently evaluating open-source OCR frameworks to select a suitable base model for fine-tuning, with the goal of achieving state-of-the-art recognition performance for Uzbek text.
Benchmarking Open-Source LLMs for Uzbek Language Tasks (to be published September 27, 2025)
Khasankhon Yusupkhujaev
Independent Research, 2025
Benchmarked seven small-scale (0.6B–2B parameters) open-source LLMs on Uzbek translation, comprehension, and generation using a custom 180-example dataset. Implemented zero-shot evaluation pipelines on a RunPod A40 GPU with Hugging Face Transformers, achieving a top BLEU score of 0.54 for Kimi-K2-Instruct. Released dataset and code publicly, providing insights for low-resource NLP and fine-tuning in compute-constrained environments.

Predicting Match Outcomes in The Hundred Cricket Format: A Machine Learning Approach
Khasankhon Yusupkhujaev, Fred Worral (Supervisor)
MSc Dissertation, Durham University, 2024
Conducted predictive modelling using machine learning to analyse outcomes of cricket matches. Engineered and evaluated complex features including win rate, moving averages, venue effects, and head-to-head statistics. Explored fairness and politics of data production and processing in sports analytics.
